# Great Smoky Mountains

An interactive comparison of the 10-cent Great Smoky Mountains stamp and a photograph of the same landscape. Drag the divider to trace the pine and ridgelines. Use the full-image buttons to inspect the complete scans.

## Publish on GitHub Pages

1. Unzip the package. In a new GitHub repository, upload the extracted contents together. Place `index.html` and the `assets` folder at the top level and commit to `main`. Include `.nojekyll` and this README.
2. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**. Click **Save**.
4. Once deployment finishes, return to **Settings → Pages** and click **Visit site**.

GitHub Free supports Pages in public repositories. See [GitHub’s publishing guide](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Preview and edit

Open `index.html` in a browser to preview the exhibit locally. Keep the `assets` folder beside it. Edit the page text in `index.html`, the layout in `assets/styles.css`, and the divider and original-image controls in `assets/comparison.js`.

The two WebP files contain the aligned landscape details. The JPEG files contain the complete original scans and load when their respective buttons are selected.
